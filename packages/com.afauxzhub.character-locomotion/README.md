# Afauxzhub Character Locomotion

这是个人项目的第三人称移动数学层，不是完整角色控制器。

当前提供：

- 相机相对输入到世界方向的转换。
- 独立于 Input System、Cinemachine 和动画插件的朝向求解器。
- 以速度/转弯半径约束转速，并输出朝向误差、实际转速和动作混合意图。
- 八方向起步分类，为后续多方向起步动作预留稳定接口。
- 小转向进入/退出迟滞，避免动作在阈值附近抖动。

接入时由项目自己提供三类适配器：输入、碰撞/位移 Motor、动画 Presenter。不要让本包直接读取全局输入、控制镜头或播放动画。

当前仅完成源码静态检查；需要在个人 Unity 工程中用手柄、键鼠和目标动作进行灰盒验收。
