## 目标

锁定目标时角色保持面向目标，在前后左右及四个斜向移动；方向、步态和自由/靶向模式切换连续。

## 范围

- 包含：方向×步态混合、靶向起停/换向、目标移动与丢失、两套姿态、自由/靶向模式交接；资源矩阵明确 Walk/Run/Sprint 的方向覆盖。
- 不包含：锁定目标选择产品化、镜头系统重做、动态锁脚；不擅自把靶向 Sprint 或某姿态缩减为禁止。

## 验收条件

- [ ] 两套前/后/左/右与四斜向均有明确配置，保持面向目标且移动速度/方向显示准确。
- [ ] 八方向连续混合、急反向、靶向起停与步态切换不出现方向跳变；需要桥接的动作可以通过同一配方编辑。
- [ ] 靶向走/跑/冲刺覆盖按资源矩阵逐项记录；若资源不能覆盖某组合，保持缺项，不私自修改允许移动的设计范围。
- [ ] 自由→靶向、靶向→自由、目标移动/丢失、移动中切姿态的朝向和动画交接可控。
- [ ] 真实方向动画的姿态与位移方向相符；无资源时 Idle 滑动保持警示，不能算表现通过。
- [ ] 更新本卡证据、缺项和交接，并同步唯一任务索引；机制通过不代替真实表现通过。
