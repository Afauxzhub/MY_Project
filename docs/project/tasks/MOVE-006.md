## 目标

角色能根据方向变化选择原地转身、90 度转向、连续弧线/急弧或 180 度折返，并自然衔接回移动。

## 范围

- 包含：两套左右转向、速度/角度区间与迟滞；原地及移动 90 度转向、180 度折返；跑步/冲刺弧线混合，走速适用方案显式配置；可选其他角度变体只按实际资源添加。
- 不包含：Motion Matching、动态锁脚、未确认的自动镜头控制改造；不把所有转向角度都扩成主 FSM 状态。

## 依赖

MOVE-005 换挡机制可用；原始单个折返需方向审核，缺双侧/90 度转身组与战斗弧线资源。

## 验收条件

- [ ] 小角度转向、弧线、急弧、90 度、折返的选择条件/优先级及实际命中配方可见，阈值和迟滞为可调数据。
- [ ] 左右连续转向及跨 ±180 度方向边界不反复翻边；可在转身/折返中松键、改向、继续加速并得到明确衔接。
- [ ] 程序旋转/位移与 Clip 转向配合，Motor 仍唯一写根；有 Root Motion 时不重复应用 Clip 和程序 yaw。
- [ ] 相机右键旋转与世界移动意图、角色朝向分离，镜头变动不意外反复触发折返。
- [ ] 两套在走/跑/冲刺适用速度下实看转身重心、出脚和弧线倾身；用 Idle 旋转或直跑代替转身/弧线不能算通过。
- [ ] 更新本卡证据、缺项和交接，并同步唯一任务索引；机制通过不代替真实表现通过。
