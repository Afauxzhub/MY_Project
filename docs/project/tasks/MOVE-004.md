## 目标

从待机按不同方向输入时出现匹配起步，松键时按支撑脚停下，中途改变输入仍连续返回移动。

## 范围

- 包含：两套姿态、多方向起步意图、走/跑/冲刺适用的起停配方、左右支撑选择与入口/出口相位；短点按、起步中松键、停步中再起步的衔接。
- 不包含：动态锁脚、完整加减速换挡、转向/折返及跳跃。支撑相位标记属于动画选择数据，不代表锁脚实现。

- `docs/architecture/locomotion-framework.md`、`docs/architecture/company-reference-reuse-review.md`。
- `docs/design/combat/player-combat-spec.md`、`docs/design/combat/integration-contracts.md`；涉及动作打断时遵守 ATK-05..07、SKILL-05..06、HIT-01..03、COUNTER-01..02，不封口未确认规则。

## 依赖

MOVE-003 基础循环机制可用；需要审核多方向 Start 及不同速度 Stop 资源。主城有一组 Start/左右 Stop，战斗缺另一侧 Stop，不能默认覆盖所有方向/步态。

## 验收条件

- [ ] 两套各方向起步按输入相对角色朝向选取；允许经过审核的共享/混合方案，但不能把正前起步当全部方向已验。
- [ ] Idle→Start→循环、循环→Stop→Idle 的 Clip、桥接时间、退出相位及运动曲线都从配方配置。
- [ ] 左右停步选择依据可见的循环支撑相位；缺侧显式标记，不随机播放、不默认镜像 Generic 骨架。
- [ ] 起步中松键、连续短点按、停步中反向/再起步以及临近边界的新输入不锁死、不突跳、不不断重置过渡。
- [ ] 关闭 IK 后审查起停的身体重心、根位移/程序速度与落脚时机；两套及适用步态真实衔接通过。
- [ ] 更新本卡证据、缺项和交接，并同步唯一任务索引；机制通过不代替真实表现通过。
