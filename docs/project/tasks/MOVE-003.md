## 范围

- 包含：建立姿态×自由/靶向模式×步态×方向/动作族的资源需求矩阵；先实现自由移动基础循环、速度/步频映射和双套切换；IdleVariation 作为明确可开关的变体，不以赋槽代表自动播放。

- [ ] Walk/Run/Sprint 速度阈值、迟滞、循环相位和混合可配置；关闭 IK 也不出现因循环重置造成的每帧抽动。
