## 实接发现与修复

- 初次落地无输入仍从 Land 转 Stop：真实 Stop 自带前移，因此“待机”漂移。改为静止落地回 Idle，补 15/30/60/120 步长逻辑回归。
- 循环姿势先采样后推进时钟，导致根位移迟一帧：一次 0.333s 卡顿后，0.003s 短帧实际收到约 1.39m 位移。改为当前帧末端统一采样；加入交替长短帧及跨圈断言，不以放宽距离阈值掩盖问题。
- 根转向每帧调用 Reset 清空加速度，30/60/120 帧率半秒转向分别约 20°/10°/5°。改用只同步实际朝向的接口，保留角速度与转向滞回，显式 Reset 的行为不变。
- 新场景打开会卸载尚未引用的新配置：创建工具在切场后重新加载配置再绑定，避免空引用落盘。独立副本重开验证已通过。
- 缺靶向 Clip 回退已启用根运动的 Idle 时，零位移待机占满根权重，Play 实测期望/平滑速度 3.5m/s、Motor 速度 0。现改为只借缺项姿势、保留程序移动；缺方向起步也不借错误前向轨迹。真正缺根数据仍报错并保持位移，原配置不被改写。新增双套靶向缺项/返回自由移动共 4 段回归。

核心契约在动画架构 0.7/0.8；本卡只记录发现和验收，不复制实现规范。新版核心 692 条、纯逻辑 64 条、追加缺资源回退后的三档真实回放及最终程序位移地形矩阵均已通过。
