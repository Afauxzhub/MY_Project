## 目标

走、跑、冲刺之间有可调节的身体动作与速度变化；松开冲刺能减速回跑/走，松开移动能减速停下。

## 范围

- 包含：两套 Walk↔Run、Run↔Sprint 及需要的跨挡配方；可选 Accelerate/Decelerate 桥接；速度/播放时间曲线、节奏衔接与换挡中断。
- 不包含：急转、靶向全方向、跳跃、动态锁脚；不增加体力/耐力消耗或其他未确认战斗规则。

## 验收条件

- [ ] 按住/松开冲刺与走速输入得到可解释的换挡配方；目标速度、实际速度、动画进度分别显示。
- [ ] 速度曲线、桥接 Clip、入口/退出点、融合曲线和循环相位可分别调节，改表现不修改战斗窗口。
- [ ] 加速未完成即减速、减速中再次冲刺、直接松键停下时能够连续衔接，不回到错误速度或重启旧桥接。
- [ ] 30/60/120 fps 目标与大帧步下阶段切换稳定，实际采样帧率记录在证据中，不把目标帧率当性能基准。
