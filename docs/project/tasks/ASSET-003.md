## 目标与范围

让当前隔离参考角色在无连线动画工作台和独立测试场景中显示原始贴图，便于判断动画姿势与衔接。只读解析源 Prefab 的 Renderer → Material → Texture 引用，复制必要资源到本地忽略目录；源 Shader 不兼容时制作个人测试用兼容材质，不迁移公司渲染管线。保留原始材质副本和映射证据。

不修改公司资产、Max、原有场景、动作参数或战斗规则。不保存、丢弃或重载用户工作台中的未保存草稿。参考资产、原材质、报告和源路径均不提交。

## 权威依据与依赖

- `docs/production/asset-workflow.md`：本地隔离、稳定引用和禁止提交公司资源。
- `docs/project/tasks/MOVE-002.md`、`MOVE-003.md`：现有工作台与双套资源覆盖基线。
- 用户本轮授权读取并搬入当前参考角色材质；Unity 6000.3.24f1 个人实例可用。
