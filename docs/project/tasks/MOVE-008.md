## 目标

两套姿态下可从待机/走/跑/冲刺起跳，经空中与下落落地到待机或继续移动，包含完整动画链。

## 范围

- 包含：Motor 垂直速度/起跳请求、接地/顶碰、水平惯性与可调空中控制；起跳/上升/空中/下落/落地配方，离开台阶的下落；自由与靶向模式；独立可配置跳跃输入。
- 不包含：二段跳、攀爬、空中战斗、跳跃无敌、受击脱离或新取消许可。它们不是本次移动动画需求的隐含授权。

## 验收条件

- [ ] 跳跃输入可单独绑定且 HUD 可见，不覆盖当前 Space 闪避；仅合法接地/许可状态接受请求，连续按键不意外二段跳。
- [ ] 两套待机及走/跑/冲刺均能起跳，包含空中/下落和落地后 Idle 或继续移动；允许一个 Clip 覆盖多个阶段但有明确阶段映射。
- [ ] 水平惯性、空中控制、起跳高度/重力与落地混合独立可调；角色最终位移/旋转只由 Motor 写，动画不另写 Transform。
- [ ] 顶碰、落边、坡面落地、短时离地抖动与不同输入下落地均有稳定阶段判定；接地瞬间不能反复重播 Land。
- [ ] 起跳/落地附近松键、转向、锁定目标变化和姿态请求有明确处理；不能让动作编辑器自行赋予攻击/受击取消权限。
- [ ] 真实动画完成两套待机跳与移动跳全链人工观察；仅胶囊离地、Fall/Land 占位或在地面播放跳跃 Clip 均不算通过。
- [ ] 更新本卡证据、缺项和交接，并同步唯一任务索引；机制通过不代替真实表现通过。
