## 实际实施与验证

- 使用 Max 2020 独立批处理构建、保存并重新加载，场景共 1,256 个对象，保留 609 根原变形骨。名称无重复，原骨名的 `G_` 前缀已移除；参考高度 1.8 米，沿用原素材 30 fps。
- 主身体和手指共 54 对驱动映射；`Head_Attach` 接到 Bip Head。增加 552 个附加 FK 控制及 1 个面部参数控制，17 处基础关节跟随。下唇、下排牙齿和舌头跟随下颌。
- 直接 `rescaleWorldUnits` 曾使本素材 Skin 参考网格产生约 0.31 米误差，未采用该结果。最终在参考姿势缩放保留拓扑/UV/材质的网格与原骨架，将逐顶点影响骨、权重、DQ 权重转移到重新建立的 Skin。参考网格最大误差 `3.74984e-7 m`；权重最大差 `1.19209e-7`；DQ 权重差 `0`。
- Biped Figure 模式拟合依据实际求值矩阵修正；手臂与脚部关节位置检查通过。原 pelvis 和 clavicle 中间骨的参考偏移有意保留，膝部保留约 2 mm 预弯。
- Root 平移误差 `8.37287e-7 m`，旋转误差 `7.51817e-7 m`。眨眼参数使上眼睑移动约 13.86 mm；张口测试影响 1,367 个网格顶点。
- 在测试副本制作 0–60 帧身体、头部、手指、抬脚、披风、面部和 Root 动画；网格范围检查通过。Biped 原生关键帧/姿态接口需兼容 Max 2020，并显式同步时间滑块。测试初始姿势误差 `5.09385e-7 m`。
- 保存测试 `.max` 后重开：与文本参考点对比最大误差 `5.48395e-6 m`（文本坐标有精度截断）；30 帧眨眼 90、张口 10、60 帧 Root 位移 0.5 米均保留。
- 独立 `ExportAnimation.ms` 导出 610 个节点、61 帧；临时烘焙与源矩阵最大差 `1.80943e-6`。FBX 回读需显式启用单位转换并设目标为米；本机已有导入设置会造成 100 倍误差。明确设置后，610 个节点、30 fps、5 个采样时刻的回读检查通过，位置误差 `9.62931e-7 m`、基向量差 `1.31031e-6`。
- 正式绑定文件不包含上述测试动作。原材质保留；灰色预览仅用于检查形体，不能代替原材质下的面部和透明贴图检查。

Max 启动时本机原有脚本仍有 Python SyntaxError，批处理返回码不是干净的 0。本任务以生成文件重开、逐项数值检查、`KY_BUILD_OK`、`KY_VALIDATION_OK`、`KY_ROUNDTRIP_OK` 为证据，不把全局 Max 环境描述为无错误。
