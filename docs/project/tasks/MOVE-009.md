## 验收条件

- [ ] 覆盖两套姿态、自由/靶向模式、Walk/Run/Sprint、起停、加减速、弧线/90 度/折返、待机/移动跳的可达组合；清单显示通过/缺资源/失败，不只看单段 Clip。
- [ ] 正常链与打断链均测：半途松键/反向/换挡、边界输入、姿态/目标切换、起落地、移动→动作→移动；没有无法退出的状态或重复自中断。
- [ ] 同 L1 重入保留淡出姿势时钟，代表性受击/取消优先级、活动窗口清理和表现/玩法时序独立回归通过；不改变规范规则。
- [ ] 更换第二个角色仅配置模型/绑定、动作库和必要覆盖；无需复制 Controller、修改动作名称分支或重画状态关系。不同骨架确需重定向时显式报告，不虚构通用性。
- [ ] Play 修改配方后可显式保存并重开复现；不保存时能丢弃；资源增删/替换具有影响提示、Undo 和缺项报告。
- [ ] 30/60/120 fps 目标与连续输入压力回归、Unity Console/程序集检查通过，记录实际采样及原场景保护；程序位移与 Root Motion 验收结果分开。
- [ ] 关闭动态 IK 的基础动画链真实表现通过：无占位冒充方向/转向/跳跃；速度/步长与相位基础校准完成，剩余脚滑问题明确交给 MOVE-010。
