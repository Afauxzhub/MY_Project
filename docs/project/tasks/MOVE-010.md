## 目标

完整移动链稳定后，再解决支撑脚动态锁定、脚滑、过渡接触权重和坡面/台阶行走质量；不会用 IK 掩盖前序动作/速度错误。

## 范围

- 包含：真实步态接触曲线、落脚/释放、过渡中接触权重和相位、锁定失效/可达性、脚底朝向、动态地形与骨盆补偿；起跳/空中/落地的 IK 权重交接。
- 不包含：提前重写移动规则、改源动画曲线、改 Motor 轨迹以追脚，或将静态脚踝目标误差等同整脚质量。

恢复条件：MOVE-009 功能/衔接与基础资源表现通过，移动策略与步长已校准。用户明确要求放在移动动画功能最后；此前只保留已有静态 IK 开关/必要回归，不新增动态锁脚功能。

## 验收条件

- [ ] 每套有效 Clip 的接触/支撑数据经预览及真实步态确认；默认 0 不猜测接触，融合时按来源/目标相位处理接触权重。
- [ ] 支撑脚在地面保持稳定、摆动脚正常抬起；锁定/释放、距离超限、转向/折返与动作中断不拉扯腿链。
- [ ] 静态平地/坡面/台阶回归及连续移动跨坡/台阶通过；分别记录落地瞬态和稳定段，不仅报告最后一个样本。
- [ ] 跳跃/空中不被 IK 拉回地面；落地权重恢复可调且不突然压脚，脚底朝向和骨盆补偿符合实际骨架。
- [ ] 禁用 IK 恢复视觉骨架，不累积偏移、不改源 Clip；Motor 位置/旋转所有权不变。
- [ ] 双套所有已验移动与中断链在 30/60/120 fps 目标下复测；同时提供人工观感与支撑脚世界速度/漂移、穿地/离地、目标误差证据；容差先按角色尺度登记为调参值再验收。
- [ ] 更新本卡证据、缺项和交接，并同步唯一任务索引；机制通过不代替真实表现通过。
