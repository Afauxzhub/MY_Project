## 项目目标

制作第三人称动作游戏，并先通过最小灰盒验证玩家战斗循环。当前阶段优先建立稳定工程、接入已有通用包、验证基础运行链，再进入完整战斗灰盒。

玩家战斗设计以 `docs/design/combat/player-combat-spec.md` 为唯一权威来源。程序、动画、Boss 和 AI 需求通过规则 ID 引用该规范，不在本文件复制完整设计。
