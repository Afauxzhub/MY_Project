## 继续制作

- 默认在本目录下新建原画版本子目录，保留旧图；用户明确指定版本时以其为准。
- 四视图集中存放；单面修改时记录实际变更面和沿用面。
- 同目录的 `generation-notes.md` 记录来源与修改内容；迁入旧记录中的历史路径只作追溯，不作为现行文件入口。
- 新角色使用 `ArtSource/Characters/<角色代号>/Design/`，不放入本角色目录。
